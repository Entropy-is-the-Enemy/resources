# Constraints file template

Copy to the pack folder as `constraints.md` and fill every line. Agents read this before the
section. Anything not written here is not enforced.

```
# Constraints: [document] / [section]

## Audience
[who reads it, what they will check, what decision they make with it]

## Register
- formal / [no contractions] / [no first person] / [no em dashes]
- other house rules: [e.g. sentence case headings; numbers under ten spelled out]

## Number and naming conventions
- currency: [e.g. $246,000, no decimals; "$1.2M" never]
- percents: [one decimal / whole]
- fiscal labels: [FY27 / 2027 / "the 2027 plan year"]
- product and org names, exact spelling: [list]

## Facts on the author's authority (must survive in substance)
- [fact 1, with the paragraph it currently sits in]
- [fact 2]

## Rulings already taken (do not re-open)
- [date] [ruling, one line]

## Sources in the pack
- [file]: [what it is the source for]

## Editing tools for this document
- format: [docx / md]
- backup pattern: [e.g. <name>.pre-<tag>-<YYYYMMDD>-<n>.docx]
- edit log: [path]
```
