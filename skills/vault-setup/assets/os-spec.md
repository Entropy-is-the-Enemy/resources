# Operating system spec: staged files

These files are defined now and created on first use. When a trigger fires, create the file in `00 Operating System/`, name it in `00 Operating System/_REFERENCE.md`, and remove its row from this table.

| File | What it is for | Created when |
|---|---|---|
| `action-register.md` | One list of open action items, each with an ID like ACT-01, an owner and a due date | The first time a file or a meeting shows something a named person must do. If the owner or the due date is missing, ask; do not fill it in |
| `rulings-ledger.md` | Standing decisions about how the vault works, dated, so they are not argued twice | The first standing ruling about how the vault works |
| `Email Digests/` | Short summaries of filed emails, so the thread can be found without opening each message | The first email is filed through the inbox |
| `vault-health.md` | The result of each tidy pass: what was checked, what was fixed | The first vault tidy pass |
| `vault-tidy-queue.md` | Items a tidy pass saw but put off, with the reason | The first item a tidy pass defers |
